# New Project Setup Prompt

Use this prompt with the agent after placing this `.agents/` directory in a project:

"Read `.agents/AGENTS.md` and the relevant rules/skills. First inspect the existing repository without modifying it. Help me define this project's product context, requirements, technology choices, visual direction, and risks. Do not reuse another project's theme. Mark assumptions and ask only blocking questions. Then prepare project documentation and, for complex workflows, user/business/system/error flows. Verify available Figma/FigJam tools before attempting native board creation. Implement only after scope and required decisions are clear. Use the project's existing stack unless we explicitly approve a change. Verify functionality with the available tests and browser, and report exactly what was verified."
