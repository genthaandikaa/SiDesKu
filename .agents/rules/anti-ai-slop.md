# Anti-AI-Slop Design Standard

## Core test
“Every element must earn its place. If an element does not improve usability, hierarchy, or communication, remove it.”

“Design with intention. Prioritize clarity over decoration. Use restraint over excess. Never add visual complexity without meaningful purpose.”

## Avoid by default—not as absolute bans
- Repeated cards where a table, list, section, or plain layout is clearer.
- Excessive badges, pills, gradients, shadows, borders, icons, and decorative labels.
- Generic hero sections, arbitrary floating blobs, meaningless charts, and filler metrics.
- Dense layouts with weak hierarchy or oversized whitespace that harms information density.
- Repeated identical page compositions regardless of product context.
- Placeholder copy, fake testimonials, fabricated metrics, and decorative controls.

## Required design reasoning
For meaningful screens, determine:
- Primary user task and most important information.
- Content hierarchy and scan path.
- Appropriate density for the product and audience.
- Why each major visual treatment exists.
- Responsive behavior and accessibility.
- Empty, loading, error, success, and disabled states.

Cards, gradients, animation, shadows, and visual effects are allowed when they serve a clear purpose. Do not mechanically ban them.

## Project individuality
Create a new visual direction for each project from its brief and references. Do not reuse a previous project's theme by default. A design system is a coherent set of project-specific decisions, not a universal aesthetic.
