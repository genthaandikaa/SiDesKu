# Skill: Project Planning

For new projects and substantial features:
1. Extract goals, target users, roles, scope, constraints, assumptions, integrations, and success measures.
2. Separate confirmed requirements from assumptions and open questions.
3. Create/update PRD, requirements, feature specification, acceptance criteria, and task breakdown under `.agents/project/`.
4. Identify risks, dependencies, data/security concerns, and out-of-scope items.
5. Recommend a proportionate plan and sequence.
6. For multi-actor, branching, high-risk, or consequential features, invoke Flow Intelligence before implementation.
7. Keep planning documents concise, actionable, and synchronized with implementation.

Do not force a heavyweight PRD for a small bug fix. Ask only questions that materially affect the solution.
