01 · Ringkasan Eksekutif & Identitas Proyek

Visi, misi, dan latar belakang transformasi digital Desa Doko

SiDesKu (Sistem Informasi Desa Terpadu) dirancang untuk menyelesaikan birokrasi konvensional di Desa Doko, Kecamatan Ngasem, Kabupaten Kediri. Mengintegrasikan pelayanan administrasi publik, penerbitan surat pengantar dengan validasi QR digital signature anti-pemalsuan, transparansi APBDes, kas warga tingkat RT, dan penyaluran bantuan sosial.

🎯 Target Utama Transformasi
  • ✅ Warga bisa ajukan 10+ jenis surat kapan saja via HP
  • ✅ Persetujuan digital berjenjang: RT ➔ RW ➔ Sekdes
  • ✅ Surat sah ber-QR Code tanpa perlu tanda tangan basah
  • ✅ Warga bisa lacak posisi berkas realtime via Nomor Resi
  • ✅ Publikasi grafik APBDes transparan cegah korupsi dana desa
⚙️ Stack & Spesifikasi Mesin
  • Frontend : React 19, TypeScript, Tailwind CSS v4, Vite
  • Backend : Laravel 13, PHP 8.4+, MySQL Relational DB
  • Keamanan : Laravel Sanctum API Tokens, SHA-256 Hashes
  • QR Code : SVG Dynamic Generator with Route Resolution
  • Casting : JSON attributes for flexible dynamic forms

07 · Gap Analysis & Masalah Teknis Backend

Temuan kritis pada kode saat ini yang harus diperbaiki pada Fase 1

1. Bug Alur Surat Skip RW

Di RtSuratController::approveRt(), status langsung meloncat ke processed_sekdes. Seharusnya diarahkan ke approved_rt sehingga Ketua RW bisa menjalankan verifikasi sebelum sampai di meja Sekdes.

2. Belum Ada Middleware RBAC

Endpoint hanya dilindungi oleh auth:sanctum generik. Pengguna dengan token warga masih berpotensi memanggil endpoint persetujuan surat jika tidak dicegah via middleware role check.

3. Pagination Belum Diaktifkan

Pemanggilan data warga dan surat masih menggunakan ->get() penuh tanpa limit. Saat data mencapai ribuan warga, respon JSON akan melambat drastis.

4. Penyimpanan Avatar Base64

Penyimpanan avatar sebagian masih mengandalkan string base64 pada kolom text yang membebani database, sebaiknya distandarisasi ke file storage Laravel.
